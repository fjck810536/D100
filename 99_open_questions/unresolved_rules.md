# 已收束，不再視為未決

## 一般攻擊「雙方都失敗」問題 — 已排除

`戰鬥流程` 與 GM 實際流程已確認：

```text
宣告輪
→ 動作輪
→ 確認沒有改動作
→ 攻擊者先做攻擊檢定
→ 攻擊成功
→ DM 才宣告防守方擲閃避
→ 比較雙方「過多少」
```

因此攻擊本身若先失敗，通常不會再要求防守方擲閃避；不能拿兩個負值直接比較當一般攻擊通則。

## Lv0 / 未購技能 — 已由 Sheet + 角色卡交叉回答

```text
Lv0 cost = difficulty
空白／未購 ≠ 已購 Lv0
```

Lv0 移除「空丟」-20，但沒有 Lv1+ 的等級加值。詳細證據見 `sources/CHARACTER_EVIDENCE.md`。

## 屬性 adjustment 延伸公式 — 已由角色卡交叉回答

多張新舊角色卡一致使用：

```text
adjustment = ROUND((current raw stat - 13) / 2)
```

## 知識基值的 ×1.5 取整 — 已由角色卡交叉回答

多張角色卡模板明確使用：

```text
ROUNDDOWN((INT總值 + WIS總值) × 1.5)
```

注意：只回答知識基值，不外推成全域小數處理。

## 疊骰（doubles）作為事件 hook — 已確認存在

多張角色卡／技能／物品會監聽 `11 / 22 / 33 ...` 等疊骰事件。

這只代表「疊骰是一個可被條文監聽的骰面事件」，**不代表疊骰本身是全域大成功／大失敗或固定 bonus。**

## 自然大成功／大失敗骰面 — 已確認

後續 GM 補答已覆寫第一輪 provisional：

```text
自然 01 = 保證大成功
自然 00（100） = 保證大失敗
```

兩個自然骰面不因最終數值修正而失去特殊狀態。D100 不採 CoC 的比例成功／困難成功／極難成功。

第一輪 `自然 100 = 大成功／大失敗未知` 僅保留於 `sources/GM_PROVISIONAL_2026-09-12.md` 作歷史 provenance，並已標記 `[SUPERSEDED]`；runtime 不得採用。

## 專注／戰鬥施法 — Round 2 已回答

`專注` 不再視為另一個隱藏技能；D100 由 `戰鬥施法` 承載：

```text
未購戰鬥施法 → 戰鬥基礎值 -20
戰鬥施法 Lv0 → 戰鬥基礎值，不吃 -20
戰鬥施法 LvN → 戰鬥 + N×10 + 其他適用修正
```

凡對施法行為造成實際干擾的情況，可以要求戰鬥施法／專注判定。3.5 `Concentration` 只用來提供干擾情境與邏輯，不直接倒灌其數學。

`移動施法` 是安全移動額度，不是另一個專注技能：

```text
安全移動距離 = 技能等級 × 10 ft
```

詳細來源：`sources/GM_CLARIFICATIONS_2026-09-12_ROUND2.md`。

## 搜集資訊 — Round 2 已回答

GM 已明示可用 3.5 `Gather Information` 作 reconstruction source：

```text
搜集資訊（交涉，難度1）
判定 = 交涉 + 技能等級×10 + 其他修正
未購 -20；Lv0 移除未受訓減值
一般城市／社群重大消息：須過10
特定傳聞／物件／地點：通常須過15～25
典型耗時：1d4+1 小時
```

`調查員` 與 `地方知識` 的既有加值照常套用。這是 **3.5 source + GM 明示採用**，不是假裝目前 Sheet 中還存在一條遺失列。

詳細來源：`sources/GM_CLARIFICATIONS_2026-09-12_ROUND2.md`。

## P0-2 自然大成功／大失敗與其他機制的交互

**骰面與攻擊型 exceptional outcome 已確認。**

已確認：

- 自然 01 = 保證大成功。
- 自然 100 = 保證大失敗。
- 攻擊／傷害的自然 01 包含武器既有爆擊品質，最終結果由 AO 依角色 intent 與世界條件裁定。
- 大成功／大失敗採「可能性的野獸」原則：心想事成式 exceptional success／墨菲定律式 exceptional failure。

本項剩餘交互問題：

- 技能條文中的個別「大成功」是否完全沿用自然 01，還是另有特例？
- 疊骰與自然 01 / 100 同時出現時，若有監聽疊骰的技能，事件如何並存？
- 個別武器／專長若同時指定自己的爆擊範圍與特殊效果，和自然 01 的 exceptional outcome 在複合效果下如何排列與記錄？

詳細補答見 `sources/GM_CLARIFICATIONS_2026-09-24_CRITICAL_RESULTS.md`。

## P0-2A 章節張力／情節張力的正式定義

2026-09-24 GM 補答允許 AO 在自然大成功／大失敗等 exceptional adjudication 中，把「章節張力／情節張力」作為次級權重，生成與既有世界因果相容的額外事件。

待規格化：

- 章節張力與情節張力分別代表哪些可觀察／可記錄狀態？
- tension state 的 owner、來源與生命週期。
- AO 取得 tension signal 的資料結構。
- tension 對結果可以影響哪些維度：事件追加、時機、揭露、位置、代價、機會等。
- tension basis 如何記錄 provenance，讓事後能區分「世界因果」與「敘事權重」。
- tension 如何和 Mystery / World Commitment / hidden truth 共存。
- tension 在 persistent campaign 與 isolated dry-run 中的相同／不同資料需求。

在正式 schema 建立前，AO 使用 tension 時留下明確 basis，並以 committed world causality 作為第一層錨點。

## P0-3 移動公式：已知有角色卡實作，但版本／模板不一致

Sheet `戰鬥流程` 明文：

```text
正常移動上限
= (DEX調整值 + 各式技能專長 + 魔法物品變動值) × 5 ft
```

GM 已確認實際跑團通常照角色卡格數處理，且角色卡存在獨立移動欄。

角色卡考古目前觀察到：

```text
約翰 v1.2：移動 ≈ DEX adjustment
喀爾烏斯 END：移動 = max(DEX adjustment, 1)
亞黛兒 v1.3：移動 = max(DEX adjustment, 1) + 1 + 其他修正
卡蘭德 v1.3：移動 = max(DEX adjustment, 1) + 2 + 瞬步／其他修正
```

因此可以排除：

```text
全系統固定 base movement = +1
全系統固定 base movement = +2
自動套 D&D 30 ft
```

仍未知：

- v1.3 的 `+1` / `+2` 分別來自種族、角色、模板版本、特殊規則還是公式 bug？
- 現行通用角色的 base movement 是否有正式欄位／公式？
- `戰鬥流程` 那條公式是完整速度、速度修正量，還是省略了一個來源？

### 安全處理

角色卡已有移動值時直接用角色卡。沒有角色卡來源時，不自行補 D&D 30 ft。

詳細證據見 `sources/CHARACTER_EVIDENCE.md`。

## P0-8 `迷魂曲` 的明文比較接口 vs 一般法術獨立豁免

一般控制／法術實務已釐清為：

```text
施法檢定成功
→ 法術成立
→ 目標做能力條文明示的獨立抗性檢定
```

不把施法者「過多少」和目標抗性「過多少」普遍拿來互相比。

但 `迷魂曲` Sheet 明文寫：

```text
吟遊：表演 + Lv×10
目標：抗控制 - Lv×10
若目標檢定結果 >= 吟遊檢定結果 → 迷魂失敗
```

仍需確認：

- `迷魂曲` 是否就是一個明文特例的主動對抗接口？
- 這裡的「檢定結果」具體比較 raw roll、總值、還是「過多少」？
- 其他吟遊／特殊技能如果有類似文字，是否同樣各自依明文處理？

在確認前，不要用一般法術流程抹掉 `迷魂曲` 的明文比較句。

# P1

## P1-1 五抗與三特殊判定的語義邊界

公式與大量能力條文已經比早期清楚很多：

```text
抗毒素：毒素／生理污染
抗控制：意志、行為、魅惑、恐懼等控制
抗轉化：形態／狀態改寫
抗噴吐：範圍／反射類能力條文明示豁免
抗魔法：能力明文指定的魔抗／穿透層；不是所有魔法自動多一骰

強韌：肉體承受
精神：心智／資訊負荷
靈魂：存在核心／靈魂層
```

角色卡已回答三特殊判定的**數學**：raw current stat ×5，不把 adjustment 再算一次。

但語義邊界仍有少數案例需累積。

## P1-3 複數判定的同時／分階段結構

已確認 D100 實務上常有複數判定：

1. **同時型**：不同骰各決定不同部分。
2. **分階段型**：前一條件成立才開下一判定。

合理例：

```text
福音傳染：初次強韌 → CON傷害 → 原始CON折半後抗轉化 → 轉化
豐饒心神：日常精神 → 失敗INT下降 → INT歸零成為傀儡
沼澤人：抗轉化／靈魂／強韌分別處理不同儀式與後果
```

仍需遵守：每增加一骰，都要能回答它決定哪個不同的機械部分或因果階段。

## P1-8 宣告順位 + 改宣告 + 反應鏈

### 設計感覺（非正式規則）

宣告順位提供資訊優勢，但玩家必須自己使用這份資訊；尤其高 INT 施法者往往需要整合盟友宣告、空間與後續風險。這一點未來玩家手冊可以用簡短故事說明，不要把它誤寫成額外數值 bonus。
