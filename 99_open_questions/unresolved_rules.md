# D100 未決規則地圖

本檔不是錯誤清單，而是防止 GPT 把空白處用其他系統習慣補掉。

在新增未決問題、套用 `[DM_DEFAULT]` / `[SRD_BRIDGE]` 或向 GM 追問前，先依序查：

1. `sources/sheet_mirror/`
2. `sources/CHARACTER_EVIDENCE.md`
3. `sources/GM_PROVISIONAL_2026-09-12.md`
4. 本檔
5. 必要時再進 3.5 SRD 對齊

優先級：

- **P0**：會直接讓一般跑團卡住或產生巨大分歧
- **P1**：常見但可暫時裁定
- **P2**：特殊內容／高階內容

# 已收束，不再視為未決

## 一般攻擊「雙方都失敗」問題 — 已排除

`戰鬥流程` 與 GM 實際流程已確認：

```text
宣告輪
→ 動作輪
→ 確認沒有改動作
→ 攻擊者先做攻擊檢定
→ 攻擊成功
→ DM 才宣告防守方擲閃避
→ 比較雙方「過多少」
```

因此攻擊本身若先失敗，通常不會再要求防守方擲閃避；不能拿兩個負值直接比較當一般攻擊通則。

## Lv0 / 未購技能 — 已由 Sheet + 角色卡交叉回答

```text
Lv0 cost = difficulty
空白／未購 ≠ 已購 Lv0
```

Lv0 移除「空丟」-20，但沒有 Lv1+ 的等級加值。詳細證據見 `sources/CHARACTER_EVIDENCE.md`。

## 屬性 adjustment 延伸公式 — 已由角色卡交叉回答

多張新舊角色卡一致使用：

```text
adjustment = ROUND((current raw stat - 13) / 2)
```

## 知識基值的 ×1.5 取整 — 已由角色卡交叉回答

多張角色卡模板明確使用：

```text
ROUNDDOWN((INT總值 + WIS總值) × 1.5)
```

注意：只回答知識基值，不外推成全域小數處理。

## 疊骰（doubles）作為事件 hook — 已確認存在

多張角色卡／技能／物品會監聽 `11 / 22 / 33 ...` 等疊骰事件。

這只代表「疊骰是一個可被條文監聽的骰面事件」，**不代表疊骰本身是全域大成功／大失敗或固定 bonus。**

GM 目前仍不確定。

- 明文 `d100 + 加值` 類的數字對抗平手

在得到完整答案前，不要把「防守方優先」說成正典。

## P0-2 全域大成功 / 大失敗的交互

GM 已補答 `[GM_PROVISIONAL]`：

- D100 有大成功／大失敗。
- **自然 01 = 保證大成功。**
- **自然 00（100） = 保證大失敗。**
- 這兩個自然骰面不因最終數值修正而失去其特殊狀態。
- 不採 CoC 的比例成功／困難成功／極難成功。
- 大成功常由 DM 給「大驚喜」，可包含額外情報、章節外情報、特殊機會或複雜後果；不是固定數字翻倍。

仍未知：

- 自然大成功／大失敗與武器自己的爆擊範圍如何交互？
- 技能條文中的個別「大成功」是否完全沿用自然 01，還是另有特例？
- 疊骰與自然 01 / 00 同時出現時，若有監聽疊骰的技能，事件如何並存？

禁止套 CoC 的比例成功層級。

## P0-3 移動公式：已知有角色卡實作，但版本／模板不一致

Sheet `戰鬥流程` 明文：

```text
正常移動上限
= (DEX調整值 + 各式技能專長 + 魔法物品變動值) × 5 ft
```

GM 已確認實際跑團通常照角色卡格數處理，且角色卡存在獨立移動欄。

角色卡考古目前觀察到：

```text
約翰 v1.2：移動 ≈ DEX adjustment
喀爾烏斯 END：移動 = max(DEX adjustment, 1)
亞黛兒 v1.3：移動 = max(DEX adjustment, 1) + 1 + 其他修正
卡蘭德 v1.3：移動 = max(DEX adjustment, 1) + 2 + 瞬步／其他修正
```

因此可以排除：

```text
全系統固定 base movement = +1
全系統固定 base movement = +2
自動套 D&D 30 ft
```

仍未知：

- v1.3 的 `+1` / `+2` 分別來自種族、角色、模板版本、特殊規則還是公式 bug？
- 現行通用角色的 base movement 是否有正式欄位／公式？
- `戰鬥流程` 那條公式是完整速度、速度修正量，還是省略了一個來源？

### 安全處理

角色卡已有移動值時直接用角色卡。沒有角色卡來源時，不自行補 D&D 30 ft。

詳細證據見 `sources/CHARACTER_EVIDENCE.md`。

## P0-4 專注技能懸空

`戰鬥施法` 明文引用「專注檢定」，但基本技能表沒有獨立「專注」。

GM 粗答 `[GM_PROVISIONAL]`：

- 實際跑團中「戰鬥施法」就是專注這條技能線的主要承載者；
- 完全未購時會出現「空丟專注 -20」；
- Lv0 可購並移除 -20；
- 概念與 `一心二用` 類似，但不是同一體系。

目前最合理的候選模型：

```text
未購戰鬥施法 → 專注基值 -20
戰鬥施法 Lv0 → 專注基值，無 -20
戰鬥施法 LvN → 專注基值 + N×10
```

仍未知：

- 專注的正式基值究竟是哪一個複合技能／屬性？
- 閃避、被傷害、擒抱、壓制、移動施法等各自何時要求專注？
- `咒法專注` 所說「受到傷害不會中斷專注」與一般專注的完整觸發條件如何對接？

### `[SRD_BRIDGE]` 候選

可參考 3.5 Concentration 的情境概念，但不可直接決定 D100 數學。

## P0-8 `迷魂曲` 的明文比較接口 vs 一般法術獨立豁免

一般控制／法術實務已釐清為：

```text
施法檢定成功
→ 法術成立
→ 目標做能力條文明示的獨立抗性檢定
```

不把施法者「過多少」和目標抗性「過多少」普遍拿來互相比。

但 `迷魂曲` Sheet 明文寫：

```text
吟遊：表演 + Lv×10
目標：抗控制 - Lv×10

```

仍需確認：

- `迷魂曲` 是否就是一個明文特例的主動對抗接口？
- 這裡的「檢定結果」具體比較 raw roll、總值、還是「過多少」？
- 其他吟遊／特殊技能如果有類似文字，是否同樣各自依明文處理？

在確認前，不要用一般法術流程抹掉 `迷魂曲` 的明文比較句。

# P1

## P1-1 五抗與三特殊判定的語義邊界

公式與大量能力條文已經比早期清楚很多：

```text
抗毒素：毒素／生理污染
抗控制：意志、行為、魅惑、恐懼等控制
抗轉化：形態／狀態改寫
抗噴吐：範圍／反射類能力條文明示豁免
抗魔法：能力明文指定的魔抗／穿透層；不是所有魔法自動多一骰

強韌：肉體承受
精神：心智／資訊負荷
靈魂：存在核心／靈魂層
```

角色卡已回答三特殊判定的**數學**：raw current stat ×5，不把 adjustment 再算一次。

但語義邊界仍有少數案例需累積。

## P1-3 複數判定的同時／分階段結構

已確認 D100 實務上常有複數判定：

1. **同時型**：不同骰各決定不同部分。
2. **分階段型**：前一條件成立才開下一判定。

合理例：

```text
福音傳染：初次強韌 → CON傷害 → 原始CON折半後抗轉化 → 轉化
豐饒心神：日常精神 → 失敗INT下降 → INT歸零成為傀儡
沼澤人：抗轉化／靈魂／強韌分別處理不同儀式與後果
```

仍需遵守：每增加一骰，都要能回答它決定哪個不同的機械部分或因果階段。

## P1-7 CP 重骰

- 1 CP 可重骰；
- 劇情骰／寶藏骰除外；
- Patch note：特殊通貨判定不可 CP 重骰。

仍未知：

- 秘密事件機制的精確門檻、機率、獎懲、重置方式。

## P1-8 宣告順位 + 改宣告 + 反應鏈

高 INT 角色後宣告；角色又可用運動檢定改宣告，再加：

- 法術瞬唱
- 即時動作
- 自由動作

已知優先度：

```text
法術瞬唱 > 即時動作 > 自由動作 = 一般動作
```

仍需壓力測試：

- 反應能否對反應再反應？
- 同一時間點多人反應如何排序？
- 是否有實際 stack 深度限制？

### 設計感覺（非正式規則）

宣告順位提供資訊優勢，但玩家必須自己使用這份資訊；尤其高 INT 施法者往往需要整合盟友宣告、空間與後續風險。這一點未來玩家手冊可以用簡短故事說明，不要把它誤寫成額外數值 bonus。

## P1-9 全域小數的取整時點

> 所有擲骰結果（包含技能檢定、攻擊、傷害）若有小數點，若 >=0.5 一律進位。

## P2-3 位面級神器與探測尺度

若個別神器設定其存在／效應與整個位面共延展：

- 探測可能處處成功；
- 但局部掃描可能失去 gradient；
- 因此「偵測到強大背景」與「能定位本體」是兩件事。

這屬個別神器／尺度裁定，不是神器分類通則。

## P2-4 3.5 內容的時間轉譯

D100 一輪 = 1 秒。

不能簡單把所有 3.5：

- 每輪傷害
- regeneration
- recharge
- 1/round power

機械地乘6或除6；必須按效果意圖與 D100 行動密度逐項轉譯。
