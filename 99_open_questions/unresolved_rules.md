# D100 未決規則地圖

本檔不是錯誤清單，而是防止 GPT 把空白處用其他系統習慣補掉。

優先級：

- **P0**：會直接讓一般跑團卡住或產生巨大分歧
- **P1**：常見但可暫時裁定
- **P2**：特殊內容／高階內容

---

## P0-1 一般攻擊「雙方都失敗」問題 — 已排除

`戰鬥流程` 已明文給出一般攻擊與閃避的處理例：

```text
攻擊90，d100=30 → 過60
閃避80，d100=40 → 過40
60 > 40 → 命中
```

GM 再次核對後確認一般實際流程為：

```text
宣告輪
→ 動作輪
→ 確認沒有改動作
→ 攻擊者先做攻擊檢定
→ 攻擊成功
→ DM 才宣告防守方擲閃避
→ 比較雙方「過多少」
```

因此原先假設：

```text
攻擊 60，骰90 → -30
閃避 50，骰95 → -45
```

再拿兩個負值比較高低，**不是一般攻擊正常會進入的流程**。攻擊若先失敗，通常不會再要求防守方擲閃避。

### 仍未解的範圍

真正同時型對抗（例如 GM 提過的「火球術對轟」）、控制總值對抗等，可能使用不同接口，需另問；不要把一般攻擊流程外推成所有對抗通則。

## P0-3 全域大成功 / 大失敗

GM 已補答：

- D100 有大成功／大失敗。
- **自然骰 100 為必定大成功，不看總加值。** `[GM_PROVISIONAL]`
- 不採 CoC 的比例成功／困難成功／極難成功。
- 大成功常由 DM 給「大驚喜」，可包含額外情報、章節外情報、特殊機會，甚至挖坑。

仍未知：

- 哪個自然骰值為大失敗？
- 大失敗是否同樣無視總加值？
- 全域大成功與武器爆擊／技能個別大成功如何交互？

禁止直接套 CoC 的 `01 大成功 / 100 大失敗`。

## P0-4 基礎移動公式疑似缺一個來源

GM 已確認：**一般角色另有基礎移動值，跑團通常照格子算，現役角色卡可查。** `[GM_PROVISIONAL]`

「戰鬥流程」明文：

```text
正常移動上限
= (DEX調整值 + 各式技能專長 + 魔法物品變動值) × 5 ft
```

因此這條不能再被當作角色完整速度的唯一來源。

仍未知：

- 正式 base movement 公式／格數
- 人類／不同體型是否不同
- 上式到底是速度修正量還是某個已省略 base 的完整式

### 安全處理

若角色卡已有移動速度，直接用角色卡；不得自行補成 D&D 30 ft。角色卡逆向工程列為下一階段高優先。

## P1-1 五抗與三特殊判定的邊界

公式明確，但不是所有超自然情境都有範例。

目前 repo 採：

```text
抗毒素：生理毒害
抗控制：行為／意志被外力支配
抗轉化：形態／存在狀態改寫
抗噴吐：反射／範圍型豁免
抗魔法：法抗／穿透層（仍待具體案例確認）
強韌：肉體承受

靈魂：靈魂／存在核心
```

GM 認為精神／抗控制／靈魂的這個切分大致接近，但邊界還沒有完全固定。

重要：強韌／精神／靈魂刻意與五抗分開，實際跑團常被獨立判定，也可能受到永久／暫時增減。

## P1-3 複數判定的同時／分階段結構

**撤回舊版「一次主要效果只准一個主要防禦」的強規則。**

GM 已明確說明 D100 實務上很常使用複數判定：

1. **同時型**：多個判定各自決定不同部分；全部命中可能造成更大後果。
2. **分階段型**：第一個條件成立後，才啟動下一個判定。

所以真正需要的不是限制骰數，而是要求每一骰都有明確機械職責。

### GPT 禁止事項

不得只因效果同時可以被描述成「魔法＋精神＋控制＋轉化」，就沒有能力依據地機械要求四連骰。

### 合理例

古神血若能力條文明確包含：

```text
毒性 → 抗毒素
精神資訊污染 → 精神
眷屬化 → 抗轉化
```

那三項可以各自決定不同後果；也可以依能力設計做成前一階段命中才進下一階段。

## P2-3 位面級神器與探測尺度

若個別神器設定其效應與整個位面共延展：

- 探測可能處處成功
- 但無法局部定位來源
- 背景與神器本體可能沒有差分

這屬神器自身特殊設計，不是神器分類通則。

不能簡單把所有 3.5 輪數乘6或除6，因為 D100 自己的行動密度已改變。

每個 duration / DOT / regeneration / recharge / 1-per-round power 都需要按意圖轉譯。
