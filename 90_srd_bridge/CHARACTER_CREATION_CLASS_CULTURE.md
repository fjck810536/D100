# 3.5 → D100 Character Creation Class Culture Bridge

> `[SRD_BRIDGE]` 本檔只用來偵測「D100 從 class chassis 改成自由 CP 後，是否漏掉職業文化／基本素養資訊」。
>
> 不能直接把 3.5 class skill / bonus language 升格成 D100 必修。

---

## 1. 使用原則

這份 bridge 只回答：

> 「3.5 為什麼把某些語言、技能、誓約、傳承或自動能力特別綁在某職業旁邊？」

它提供：

- `language_template_candidate`
- `culture_expectation_candidate`
- `required_rp_candidate`
- `source_gap_candidate`

真正要不要變成 D100 hard gate，仍須有：

```text
D100 Sheet
或 GM clarification
```

支持。

---

## 2. 明文 class-related languages

3.5 核心規則中，明文 `Class-Related Languages` 主要有：

```text
Cleric → Abyssal / Celestial / Infernal
Druid  → Sylvan
Wizard → Draconic
```

另外 Druid 會自動取得秘密語言 `Druidic`。

### D100 轉譯

目前 GM 已明確指定：

```text
施法者 hard gate = 任一難度2語言 Lv1+
```

因此這些 3.5 語言只作**基本模板推薦**：

```text
法師：龍語 Lv1
牧師：天界／深淵／煉獄語擇一 Lv1
德魯伊：德魯伊語 Lv1
```

若種族／背景已合法贈送其他難度2語言，就已滿足 D100 施法文化門檻，不需重複購買模板語言。

`Sylvan / 森林語` 仍可作德魯伊文化推薦，但若在 D100 中不是難度2語言，不能單獨拿它滿足上述 hard gate。

## 3. 11 個 3.5 核心職業的文化線索

下面不是 D100 必修表，而是自動創角的「別把角色只做成戰鬥模板」提示。

### Barbarian／野蠻人

3.5 線索：

- Survival
- Listen
- Ride
- Handle Animal
- Climb / Jump / Swim
- 歷史版本還有 literacy 限制

D100 用途：

```text
荒野／部族／邊境生活
→ 生存、感知、動物、體能候選
```

不加特殊語言 hard gate。

### Bard／吟遊詩人

3.5 線索：

- Perform
- Decipher Script
- Gather Information
- 多種 Knowledge
- 社交能力
- 技能面很廣

D100 用途：

```text
表演者／旅行者／情報節點
→ 表演、社交、文書、知識、語言候選
```

不能把吟遊做成只有「樂曲施法＋戰鬥」的窄角色而完全不檢查生活技能。

### Cleric／牧師

3.5 線索：

- Celestial / Abyssal / Infernal class-related languages
- Knowledge (Religion / Planes / History)
- Heal
- Diplomacy
- deity / domain / turning structure

D100 用途：

- 語言模板：天界／深淵／煉獄語之一；
- required RP candidate：神祇／信仰＋領域；
- 依領域／教會生活補宗教、醫療、社交、位面等能力候選。

### Druid／德魯伊

3.5 線索：

- Sylvan class-related language
- automatic Druidic
- Knowledge (Nature)
- Survival
- Handle Animal
- Heal
- Listen / Spot

D100 用途：

- 語言模板：德魯伊語 Lv1；
- 森林語作文化候選；
- required RP candidate：自然信仰／結社／傳承來源；
- 自然、生存、動物、醫療、感知能力候選。

### Fighter／戰士

3.5 線索：

- 廣泛武器／盔甲訓練
- Climb
- Ride
- Handle Animal
- Intimidate
- Swim 等

D100 用途：

若背景是正規軍、商隊護衛、騎士等，除了主武器，也應從：

```text
甲冑／盾牌／騎乘／體能／耐久／軍旅生活
```

產生候選。

不是要求所有 Fighter 都同 build。

### Monk／武僧

3.5 線索：

- Balance / Tumble / Jump
- Listen / Spot
- Sense Motive
- Knowledge (Religion / Arcana)
- Concentration
- stealth-related skills

D100 用途：

```text
武術 + 師門／修行／身心訓練
```

不應只因徒手戰鬥強就自動視為完整武僧文化。

### Paladin／聖騎士

3.5 線索：

- Code of Conduct
- Knowledge (Religion / Nobility)
- Diplomacy
- Heal
- Ride
- Sense Motive

D100 用途：

- required RP candidate：誓約／教團／信仰／行為準則；
- 宗教、貴族、交涉、醫療、騎乘能力候選。

3.5 沒有硬性要求 Celestial；若 D100 施法者需要難度2語言，可依其文化選任一合法難度2語言。

### Ranger／遊俠

3.5 線索：

- Survival
- Track
- Knowledge (Nature / Geography / Dungeoneering)
- Search
- Listen / Spot
- Hide / Move Silently
- Handle Animal
- Heal
- Use Rope

D100 用途：

避免自動生成「只有雙武器／弓的戰士」。

至少從：

```text
追蹤／生存／環境知識／感知／潛行／動物
```

廣泛產生候選。

### Rogue／盜賊／遊蕩者

3.5 線索：

- Search
- Disable Device
- Open Lock
- Local Knowledge
- Gather Information
- Forgery
- Use Magic Device
- 高技能寬度

D100 用途：

盜賊型角色通常應有很高的橫向技能密度，不要自動收斂成「匕首戰士」。

注意：3.5 沒有 5e 式 `Thieves' Cant` 作核心職業能力；若 D100 世界有黑話，應由特定組織／背景來源支持。

### Sorcerer／術士

3.5 線索：

- Bluff
- Concentration
- Arcana
- Spellcraft
- familiar

D100 用途：

不要因龍血敘事就自動強迫龍語；D100 的 hard gate 是任一難度2語言 Lv1，具體語言看種族／血脈／文化。

### Wizard／法師

3.5 線索：

- Draconic class-related language
- Decipher Script
- broad Knowledge
- Spellcraft
- spellbook / scribing / academic culture

D100 用途：

- 基本語言模板：龍語 Lv1；
- 正式教育背景可自然產生文書解讀、辨識法術、魔法物品學、魔法陣、各類知識等候選；
- 學派是 build 推薦，不是職業 hard gate。

## 4. 自動創角的安全轉譯

圖書館員讀本檔後，只能輸出像：

```yaml
source_gap_candidate:
  source: D&D 3.5 class culture
  class: ranger
  domain: tracking_and_wilderness
  suggested_d100_search_terms:
    - 追跡
    - 生存
    - 自然知識
    - 偵察
  authority: SRD_BRIDGE
```

不能直接輸出：

```text
「遊俠必須買生存1」
```

除非另有 D100／GM 規則支持。
