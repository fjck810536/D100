# D100 全表來源核對 — 2026-09-12

目的：在繼續詢問 GM 之前，先以整份 `D100專長表` 31 個 tab 作交叉核對，剔除其實已經由來源回答的問題。

> 本檔只記錄來源核對結果。上游 Google Sheet 全程唯讀，沒有修改內容或分享設定。

## 1. 一般攻擊／閃避：來源已回答

`戰鬥流程` 明文：

```text
攻擊90，d100=30 → 過60
閃避80，d100=40 → 過40
攻擊檢定結果高於閃避檢定 → 命中
```

配合 GM 實桌補答：攻擊先成功後，DM 才要求防守方擲閃避。

因此「失敗攻擊 vs 失敗閃避誰贏」不是一般攻擊的有效問題。

而且來源使用「高於」而不是「大於等於」，所以一般攻擊若最後攻防結果完全相同，按字面**不構成命中**。

## 2. D100 確實存在多種判定接口：來源已證明

不能把整套系統強迫統一成單一 roll-under 或 roll-high。

### A. 過多少／成功餘裕

```text
判定值 - d100 = 過多少
```

常見於一般技能、攻擊／閃避與「須過 N」。

### B. 明文 `1d100 + 加值` 對抗

`威嚇` 的防守方等級檢定明文為：

```text
1d100 + HP/3.5 + RES加值 + 恐懼豁免加值
```

所以 `d100 + modifier` 不是只有 GM 記憶，Sheet 本身就存在。

### C. raw d100 高值型

`素材詞綴賦予` 明文：

```text
1d100 - (素材階級 - 專長等級)×30
< 0 → 失敗
```

裝備加值、詞綴數量、狩獵收益等表也大量採 raw d100 高值區間。

結論：**每個能力／表格必須依其明文公式判定，不得建立一條假裝適用全系統的骰法。**

## 3. 控制對抗：已有大量來源，但通用「結果值」公式仍未完全抽出

來源例：

### 迷魂曲

```text
吟遊：表演 + 技能等級×10 檢定
目標：抗控制 - 技能等級×10 檢定
若目標結果 >= 吟遊結果 → 迷魂失敗
```

此能力明確支持「守方平手即可抵抗」。

### 其他來源

`自然庇護所`、`黑暗迷霧`、`統禦光環`、`絕對統禦`、`真龍威儀`、`創造奴僕`、`編演記憶` 等都明文使用抗控制。

GM 實桌補答則描述過：

```text
攻方 d100 + 加值 = 152
守方 d100 + 抗控制加值 > 152
```

目前真正需要確認的是：這種「d100 + 當前值」總值對抗在桌上適用的範圍，以及它和某些條文寫成「抗控制 - 難度修正」的關係；不是再問「抗控制是做什麼」。

## 4. 抗魔法：不是所有魔法的固定第一層

來源已足以排除「只要是魔法就一律先抗魔法」的假通則。

明文使用抗魔法的例子包括：

- `法術穿透`／`高等法術穿透`：與受術者抗魔法對抗，決定抗性減免是否被削弱／取消。
- `元素擴散`：法術命中後，再以抗魔法判定 rider（DOT、抗性削減、震懾、目盲、麻痺等）。
- `讀心`：目標抗魔法成功則無法讀表面思維。
- `耀閃衛`、`四象門徒`、`化實為虛`、多種魔法物品元素詞綴等：能力本身明文要求抗魔法。

同時，控制能力大量明文直接用 `抗控制`；範圍／反應型效果則可明文用 `抗噴吐`。

因此目前安全原則是：

> **能力寫哪個防禦接口，就用哪個；魔法來源本身不自動多送一次抗魔法。**

## 5. 複數／分階段判定：來源已直接示範

### 福音傳染

```text
初次感染：強韌
→ 感染期：每日 CON 傷害
→ 原始 CON 剩一半：抗轉化
→ 抗轉化失敗或 CON 傷害死亡：進入轉化期
```

### 豐饒心神

外神福音透過觸手＋體液接觸傳播：

```text
每日精神檢定
→ 失敗 INT -1
→ INT 歸零：化為外神魁儡
```

### 沼澤人儀式

```text
宿主寄生：每日抗轉化
記憶奪取：靈魂
外貌轉化：強韌
```

結論：D100 正典內容本身就同時存在：

- 同一主題不同效果各用不同判定；
- 前一階段成立後才進下一階段；
- 重複判定逐步累積後果。

所以不得再用「一個效果只能骰一次」作全域限制。

## 6. 強韌／精神／靈魂：確實是獨立且常用的接口

### 精神

- 幻夢境：夢中物質損失可由強韌改為精神，並可能留下恆久精神傷害。
- `豐饒心神`：每日精神判定失敗使 INT -1，最終可變外神魁儡。

### 靈魂

- `沼澤人儀式`記憶奪取。
- `星辰大樂章`部分放逐效果。
- `歸墓之力`以靈魂為核心的死亡存續檢定。

### 強韌

來源大量用於肉體承受、環境、死亡、解離、外貌轉化、過度舞蹈、CON 侵蝕等。

這支持目前的語義方向，但不能把三者變成彼此完全排斥的分類；**能力明文仍是最高優先。**

## 7. 專注：確認是真缺口，不是沒搜尋到

整表只有 `戰鬥施法` 明文提到「專注檢定」：

```text
在防禦、被擒或壓制狀態下施法／使用類法術能力，
專注檢定每等級 +10
```

另外：

- `一心二用` 是獨立技能：`感知 + 等級×10`，處理同一行動兩個不互斥動作。
- `咒法專注` 明文說專注維持咒法時，承受傷害不會打斷專注，反證一般專注法術確實可能因受傷被中斷。
- 大量技能有「維持專注／專注結束即結束效果」。

但整表仍未找到一個獨立的「專注」基本技能條目或通用專注檢定公式。

因此真正缺的是：**專注檢定的基礎值／公式與一般觸發規則。**

## 8. 搜集資訊：確認是懸空引用

整表搜尋只找到：

- 地方知識 Lv2+ → 搜集資訊 +10
- `調查員` → 每級替搜集資訊與搜索 +10

沒有找到獨立「搜集資訊」技能條目。

所以這不是「我們漏看基本專長某一列」，而是目前 Sheet 的**內部懸空引用**。

## 9. 重骰：來源大量暗示「新骰取代舊骰」，但 CP 通則本身沒寫

明文：

- 1 CP 可重骰；劇情骰、寶藏骰除外。
- Patch note：特殊通貨判定不可用 CP 重骰。
- GM：同一判定可以繼續燒 CP；DM 暗記總量，存在未公開的「業力引爆」。

其他技能的重骰條文明確常寫：

- `控制強迫解除`：無論成功或失敗，必須接受重骰結果。
- `醉漢機運`：必須接受重骰結果。
- `護符庇佑`：必須接受重骰結果。
- FATE 幸運：無論重骰結果如何皆須接受。

因此系統習慣強烈傾向「重骰替換舊骰」，但 **CP 重骰那一條本身沒有把這句寫出來**。這仍值得 GM 補答一次。

## 10. 自願目標：大量能力逐條明寫，不宜先造全域豁免規則

來源中許多能力明文要求 `自願／願意`，例如：

- 王車易位
- 隱匿通途
- 返老還童
- 高等法術抗力
- 提振戰力／激發豪情
- 多種友方祝福／傳送

因此「願意與否」是 D100 已存在的設計維度。

但尚未找到「所有抗性都可以無條件主動關閉」的全域條文；目前只能保留 GM 粗答：善意通常可接受、玩家可拒絕、DM 先描述後詢問選擇。

## 11. 基礎移動：確認存在概念，但完整公式／基礎格數未出現在目前 Sheet 通則

來源不只 `戰鬥流程` 的移動公式，還有：

- `瞬步`：不得超越「原本之基本移動能力」。
- 魔法物品詞綴 `移動力`：增加「基本移動格數」。
- 多個能力引用正常陸行速度／基本移動能力。

所以 GM 所說「另有基礎值」與來源語義一致。

但 `法師範例` 角色表也沒有看到獨立移動欄位；基礎格數／公式仍需從現役玩家角色卡或 GM 補答逆向。

## 12. 連續施法：來源幾乎能推出重置條件，但未明寫完整 reset 句

來源：

```text
上個動作為成功施法時則觸發
連續施法懲罰 = 上個法術環數×10
此減值會連續累算
```

依字面，「上一動作不是成功施法」就不符合觸發條件；因此非施法動作／施法失敗很可能會斷開連續鏈。

但目前未找到另外一條明文說「累積值於 X 時歸零」。這可以暫標 `[D100_DERIVED]`，若實桌曾有不同習慣再修。

## 13. 大成功／大失敗：目前唯一真正有來源衝突感的核心點

來源確認：

- `偵察`明文存在「大成功」。
- `折花意境`明文：對方擲骰大成功時無法使用該防禦技能。
- `序列意識`（術士）明文：攻擊／屬性／豁免骰若擲得高於序列值則壓到序列值，**「大失敗不可以」**。

GM 粗答則說：

> 自然骰 100 是必定大成功，不看總加值。

這不一定真的互相矛盾，但表示 D100 的自然特殊骰非常不適合用 CoC 習慣猜。整表沒有找到「哪個自然值是大失敗」的通則，也沒有找到一條文字直接寫 `100 = 大成功`。

這是下一輪最值得向 GM 精確確認的問題。

## 14. 真正仍需要 GM／角色卡／3.5 provenance 的項目

### GM 優先補答

1. 自然骰大成功／大失敗的精確值與優先級。
2. CP 重骰是否一定接受最新骰。
3. `專注檢定` 的基礎值／公式與一般觸發條件。
4. 控制／法術豁免中「檢定結果」在實桌上究竟如何形成；尤其 `迷魂曲` 這類雙方結果比較和 GM 所述 `d100+加值` 的對齊方式。
5. 真正對稱的同時型對抗（若存在，例如法術互撞）完全平手怎麼辦。

### 等角色卡逆向比較好

- 基礎移動格數／完整移動式。
- 強韌／精神／靈魂的額外修正來源如何落在角色卡。

### 等 3.5 source alignment 比較好

- `搜集資訊` 缺失條目的原型／分類／耗時。
- `專注` 是否部分沿用 3.5 Concentration 的情境文本。

## 核對原則

之後再向 GM 提問前：

1. 先搜整份 D100 Sheet。
2. 有明文就直接採明文，不問 GM 重複題。
3. 有多條來源時先交叉比對。
4. 只有來源缺口、來源互相矛盾、或需要實桌習慣才能決定時才問 GM。
5. 3.5 只作 provenance／補缺，不得覆蓋 D100。
