# GM 補答紀錄 — 2026-09-13 Round 3

本檔記錄針對敵方強度、總投資 CP、魔法物品等價值，以及 `化實為虛` 對高階生物成本的 GM 明確補答。

來源性質：

- `[GM_PROVISIONAL]`：GM 已明確回答桌上怎麼設計／怎麼理解。
- `[D100_CANON]`：上游 D100 Sheet 已存在的起始 CP／魔法物品配置關係。
- `[CONVERSION_CANDIDATE]`：由既有正典數列直接外推，但 GM 尚未明示採用的公式。
- `[SRD_CONTEXT]`：D&D 3.5 DMG 只作來源背景，不覆蓋 D100。

---

## 1. 敵方難度以總投資 CP 為主要設計尺度 `[GM_PROVISIONAL]`

GM 回答要點：

> 基本上只會參考 STR / DEX / INT；其他數值會看團隊強度調整要過多少。
>
> 目前團的主要判定強度已經破 100，通常會抓兩邊約 40–50 的優勢差值。
>
> CP 差距 300 以上，除非玩家有重大失敗，否則通常不會主動抓這種敵人。
>
> 最簡單的敵方設計方式，就是先看總投資 CP，再反推敵方單位可分配的總 CP。

### 現行解讀

敵方設計至少拆成兩個尺度：

```text
A. 數值／判定尺度
   參考玩家目前實際成功值（尤其 STR / DEX / INT 所支撐的接口），
   再依遭遇目的安排約 40–50 的優勢／劣勢差，而不是用 CR 直接換成功值。

B. 總 build 尺度
   以總投資 CP 作為敵方單位的主要強度預算。
```

`CP差距300+` 是目前 GM 的重要危險線：通常不作正常主動遭遇，除非是玩家先前的大失敗、特殊情境或明確高危內容。

這不是說「300 CP 永遠不可打」，而是目前團務的 encounter-design 慣例。

## 2. 3.5 CR 不直接換成 D100 CP `[GM_PROVISIONAL]`

D&D 3.5 原始 CR 仍保留作來源 threat tier / lineage 參考，但真正進 D100 encounter calibration 時：

```text
source CR
→ 只描述來源作品中的相對威脅級

D100 encounter difficulty
→ 看轉譯後怪物的總投資 CP + 具體判定值 + action economy + 特殊能力
```

所以不能寫：

```text
CR 76 = 760 CP
```

或任何未經 GM 確認的固定比例。

時空龍等來源怪物先完成 lineage conversion，再為其 D100 能力反推一份「等價總投資 CP」。這份 CP 才拿來與現行 PC 比較。

## 3. `化實為虛` 對生物：不能用「裸體所以加值=0」漏洞 `[GM_PROVISIONAL]`

`化實為虛` 的條文對暫時消除人物寫的是：SP 成本參考其身上魔法物品加值總和。

針對高階怪物／生物沒有正常玩家裝備欄的情況，GM 明確回答：

> 不要想用這個漏洞；對那種目標開下去，SP 會直接倒欠，角色會死。
>
> 生物本身的等價加值，是用其總投資 CP 換算。

因此操作上應理解成：

```text
普通裝備型人物
→ 可讀其實際魔法物品加值總和

怪物／特殊生物／沒有玩家式裝備欄的高階存在
→ 以其「總投資 CP」換算成等價魔法物品加值
→ 該等價值進入化實為虛的 SP 成本
```

所以史詩怪物「沒戴裝備」不代表 `化實為虛` 幾乎免費。

### 尚未確定

GM 尚未提供一條明文的：

```text
總投資 CP → 等價魔法物品總 +值
```

固定公式。

在公式被確認前，不得自行把任何候選比例寫成 `[GM_PROVISIONAL]`。

## 4. D100 起始配置提供了一個可追溯的候選換算 `[D100_CANON + CONVERSION_CANDIDATE]`

上游 `創角色須知` 明文：

```text
200 CP → 三件起始魔法物品 +3 / +4 / +5
250 CP → +4 / +5 / +6
300 CP → +5 / +6 / +7
```

這三點可寫成：

```text
B = CP / 50
三件標準起始物品 ≈ (B-1, B, B+1)
```

因此總加值恰好是：

```text
Σ+ = 3B = 3CP/50 = 0.06 CP
```

也就是在「標準起始配置」這個有限區間內：

```text
約 16.67 CP ≈ 1 點魔法物品總加值
```

### 保險絲

這只是由 D100 已知起始配置直接外推的 `[CONVERSION_CANDIDATE]`。

不得先假定 GM 在怪物換算／化實為虛時真的使用 `Σ+=0.06CP`；若之後 GM 給出另一條算法，以 GM 補答覆蓋此候選。

## 5. 3.5 DMG 可提供的只是概念祖先 `[SRD_CONTEXT]`

3.5 DMG 有以下相鄰概念：

- PC-class NPC 的 CR 通常等於角色等級；
- NPC 身上穿戴／攜帶的裝備視為其寶藏，並按 NPC 等級／職業查裝備總價值；
- 角色等級有預期財富表；
- 遭遇／怪物 CR 與標準寶藏價值相連。

所以 3.5 本來就有：

```text
角色／威脅層級 ↔ 裝備／財富價值
```

的設計關係。

但目前未找到 3.5 DMG 有一條：

```text
把「整個生物本身」直接折算成單一 +N 魔法物品加值
```

的 RAW 公式。

因此 D100 的「總投資 CP → 生物等價魔法物品加值」應視為本系統自己的 GM 換算慣例，而不是宣稱 3.5 原書就這樣算。

## 6. 對怪物換算流程的影響

之後來源怪物採兩階段：

```text
第一階段：LINEAGE CONVERSION
- 保留來源種族、能力結構、戰術語義、相對耐久
- 不針對目前三名 PC 平衡

第二階段：ENCOUNTER CP CALIBRATION
- 為完整 D100 怪物反推等價總投資 CP
- 與現行 PC 的總投資 CP 比較
- 檢查是否跨越約 300 CP 的非常態危險差距
- 再看主要判定接口是否形成約 40–50 的刻意優勢／劣勢差
- 最後檢查 action economy 與特殊能力是否讓單純 CP 比較失真
```

CP 是主要設計尺度，但不是唯一尺度；Time Stop、額外行動、無豁免 aura、整輪回捲等效果仍必須另外評估。

## 7. 對 Ancient Time Dragon 的下一步

上古時空龍目前的 lineage v1 先不因這份 GM 補答重寫。

下一階段應：

1. 把其 D100 九圍、技能、法術、抗性、HP/SP、時間能力等反推為一份等價 CP budget；
2. 與莎緹拉／亞黛兒／卡蘭德各自總投資 CP（或團隊遭遇尺度）比較；
3. 依 GM 的 300 CP 危險線與 40–50 判定差原則做 encounter tuning；
4. 同一份 CP budget 也可作 `化實為虛` 對該生物的等價魔法物品加值輸入來源；
5. 在 GM 明確確認 CP→+值公式前，`0.06CP` 只能作候選 sanity check。
