## 3. 種族／身體／特殊本質

### 神魔裔／阿薩托斯之子

卡面：

- CON +3、CHA +2（種族調整記錄）。
- 受到物理傷害半減。
- 自由呼吸。
- 抗噴吐／抗控制／抗轉化 +10。
- `黏菌性質 Lv1`：身體可分離並在一定輪數內黏回；分離期間依重量對運動與戰鬥產生減值。

### 靈魂的洗鍊

- 做靈魂檢定時可重骰一次。
- 在「星空」之下 SPI +1。

### 吞噬後超進化／阿薩托斯本質

卡面劇情記錄：

- 所有施法能力都來自阿薩托斯。
- 身體由阿薩托斯的意念構成。

這是角色世界狀態，不應轉成未明文的額外戰鬥 bonus。

### 終末的沸騰

卡面為傳奇級特殊能力：

```text
1/day
以自己為中心，半徑 = 技能等級×800 ft
區域轉化為「終末的神殿」
敵人不具有抗性
神殿內所有生物每輪 STR-2、CON-2
自身 CHA + 技能等級

每執行一個動作擲1D100：
- 疊骰：回復所有法術點
- 骰出7：神殿內所有生物 HP=0
- 骰出85：神殿內所有生物 HP=-20、SP=-20，並結束此技能
```

此能力極端且具有劇情層級；**不得因為角色「有這招」就自動開啟。**

## 9. 跑戰鬥時最容易漏掉的東西

1. 莎緹拉同時有 `即刻備戰 Lv3 + 一心二用 Lv1 + 法術瞬唱 Lv3`。
2. `次元錨 / 禁空 / 解析弱點 / 射線偏斜 / 任意門 / 閃現術 / 飛行術` 都是實際卡面法術，不是臨時補的。
3. 多件魔法物品直接改變 DEX / CHA / SPI / CON / SKI；舊卡的手填標籤與公式格可能不同步。
4. `終末的沸騰`、`祈願共享`、`真源解放` 是角色獨有高階能力，不屬普通術士 spell list。
5. 角色持有大量卷軸／藥水；有即刻備戰時，魔法物品啟動本身就是 action economy 的一部分。
