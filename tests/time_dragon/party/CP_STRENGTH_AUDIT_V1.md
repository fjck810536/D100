# Current PCs — CP Strength Audit v1

> 狀態：`[CHARACTER_EVIDENCE] [STRENGTH_AUDIT]`
>
> 用途：提供 GM 所說「看總投資 CP」的第一個可追溯基準。這份文件只記錄角色卡能證明的 CP 投資，不把 GM 贈與、劇情能力、未知來源能力硬折成 CP。
>
> 重要：`目前剩餘 CP` 不等於 `已投資 CP`。遭遇強度比較優先看已投入／鎖定於 build 的 CP。

---

## 1. 計算口徑

### A. 角色卡技能合計

現行 v1.3 角色卡多數技能區有自己的 `合計` 公式：

```text
技能 CP = 難度 × (2^1 + 2^2 + ... + 2^技能等級)
```

Lv0 若角色卡公式有計入，則按該欄公式處理。部分角色卡會對免費、劇情取得或特殊例外技能額外扣除 CP；應尊重角色卡自身公式，不重新用新規則覆寫舊角色歷史。

### B. 不自動計價的東西

以下分開記，不塞進本體技能 CP：

- GM 直接贈與／劇情取得能力；
- 沒有 CP 價格的特殊道具／祝福／詛咒；
- 起始或戰利品魔法物品本身的 +值；
- 來源不明的特殊技能；
- 目前未花 CP。

### C. 明寫 CP 的裝備／附法

若物品或附法明寫 `(N CP)`，先列為 `explicit CP tag`。在確認它是「目前鎖定 CP」還是單純製作價格註記之前，不與技能 CP 強行相加。

# 2. 卡蘭德

現行角色卡六類技能合計：

```text
戰鬥 30
運動 20
操作 344
感知 136
知識 412
交涉 8
```

因此：

```text
角色本體技能投資 CP = 950
```

這個數字直接來自角色卡 `合計` 公式；公式本身已扣掉若干免費／特殊取得項目。

角色卡另外維護：

```text
進戰相關投資：50
法術相關投資：872
```

兩者是用來追蹤獎勵 HP/SP 的分類統計，不等於六類技能總和；差額代表不屬於這兩個獎勵分類的其他技能投資。

目前未花 CP：

```text
196.5
```

### 明寫 CP 的裝備／附法標籤

目前主頁可見：

```text
解離術 12 CP
閃現術 6 CP
隱形術 4 CP
力場牢 14 CP
合計標記：36 CP
```

這 36 CP 暫列 `explicit CP tag`；待確認是否為現行鎖定 CP 後，才決定是否將強度帳從 950 上調至 986。

### 不計價但必須保留的能力

例如：

- 至高王座的化身（傳1；未被角色卡技能合計公式納入）
- 迷霧之觸／幽影的祝福
- 鏡系／契約／劇情能力

不得為了湊總 CP 私自估價。

### 卡蘭德 v1 強度錨

```text
[CONFIRMED_INTRINSIC_CP] 950
[EXPLICIT_CP_TAGS] +36（是否鎖定待確認）
[CURRENT_UNSPENT_CP] 196.5
```

# 4. 莎緹拉

莎緹拉使用較舊式角色卡，沒有像另外兩人那樣完整的六類 `合計` 公式。

目前可直接由技能名稱旁的 CP 註記加總得到：

```text
可見技能項目合計：約 358 CP
```

但同一張卡的 campaign note 明確維護：

```text
戰鬥 30
法術 520
```

因此至少可以確定：

```text
戰鬥／法術兩大 qualifying investment = 550 CP
```

這已經高於目前可見技能列 358，說明「法術520」包含角色卡主技能列表沒有逐項攤開的歷史法術投資／其他法術側 CP。

目前未花 CP：

```text
157.5
```

### 莎緹拉 v1 強度錨

最保守寫法：

```text
[CONFIRMED_QUALIFYING_CP_FLOOR] 550+
[VISIBLE_SKILL_LEDGER] 358
[CURRENT_UNSPENT_CP] 157.5
```

如果把目前可辨識、明顯不屬於「戰鬥30／法術520」的通用技能另加回去，工作重建值約在：

```text
[WORKING_CANDIDATE] ~588 CP
```

但在找到舊帳／玩家或 GM 確認前，不把 588 宣稱成精確總投資。

莎緹拉另有大量阿薩托斯／神魔裔／劇情能力，這些目前沒有 CP 價格，不應偷塞進 550 或 588。

# 5. 目前三人對比

只比較可追溯的角色本體 CP：

```text
亞黛兒   1338 CP
卡蘭德    950 CP
莎緹拉    >=550 CP；working ~588（舊式帳）
```

這不是完整實戰強度排名，因為：

- 魔法物品 +值差異巨大；
- GM／劇情能力沒有 CP 定價；
- 莎緹拉有大量免費／特殊存在能力；
- 角色 action economy 與 spell loadout 會放大或壓低 CP 的實際戰力。

因此後續怪物設計應採：

```text
CP budget = 第一層
主要判定值差（約 40–50） = 第二層
Action Palette / 裝備 / 特殊能力 = 第三層
```

而不是只用 CP 一個數字決定所有戰鬥數值。

# 6. 對怪物設計的使用方式

依 GM 2026-09-13 補答：

```text
先抓玩家／隊伍總投資 CP 尺度
→ 反推敵方單位可分配的 CP budget
→ 再依 STR / DEX / INT 等來源特徵分配
→ 主要對抗判定依團強度調整，常見約 40–50 優勢差
→ CP 差距約 300+ 時，通常不作正常主動遭遇，除非玩家重大失敗／特殊情境
```

對 3.5 → D100 怪物 conversion，CP 是 encounter calibration 層，不覆蓋 lineage conversion。
