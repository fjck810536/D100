If a required file cannot be retrieved, stop and report the exact missing file.

- 未選定 campaign 前，不得進入正式場景。

- ruleset 必須依 repo protocol pin 到 immutable commit SHA，不得把浮動的 main 當成既有團的固定規則版本。

必要文件成功讀取後，不要向我做規則報告。
