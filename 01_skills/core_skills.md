# D100 核心技能索引

本檔是 DM 端快速查詢版。個別技能的完整長文仍以上游 Sheet「基本專長」為準；若條目明確標為 `[SRD_BRIDGE + GM_PROVISIONAL]`，則表示原 Sheet 遺失但 GM 已允許依 3.5 補回。

## 1. 技能共通 `[D100_CANON]`

多數技能：

```text
技能判定 = 所屬技能基礎值 + 技能等級×10 + 其他修正
```

沒有該技能時通常有 -20 未受訓減值；購買 Lv0 可免除。

技能 CP：

```text
該級成本 = 2^(等級) × 難度
```

## 3. 搜索 vs 偵察 `[D100_CANON]`

來源表明確區分：

- **偵察**：注意到某事物，例如躲藏者。
- **搜索**：主動尋找、辨識細微或不尋常事物。

因此：

```text
走進房間是否注意到異常 → 偵察
主動翻查書桌暗格 → 搜索
```

## 4. 隱形不是「高偵察就看見」 `[D100_CANON]`

來源表明文：

> 偵察檢定結果大成功，通常即可察覺附近的隱形生物，**但還是看不到**。

因此 DM 要區分：

- 察覺存在
- 定位大概位置
- 真正取得視覺資訊

高技能不能憑空創造不存在的視覺訊號。

## 5. 躲藏 vs 偵察 `[D100_CANON]`

- 躲藏與可能發現者的偵察做對抗。
- 正常半速移動不受罰。
- 正常速度躲藏：-25。
- 攻擊／奔跑／衝鋒躲藏：-100。
- 已被注意時通常無法直接躲藏，除非先脫離視線／使對方分心。

## 6. 潛行 vs 聆聽 `[D100_CANON]`

- 潛行與可能發現者聆聽對抗。
- 半速無罰。
- 正常速度：-25。
- 奔跑／衝鋒：-100。

## 7. 解除裝置與陷阱 `[D100_CANON]`

- 需要適當工具。
- 無盜賊工具只用普通工具：-10。
- 精製盜賊工具：+10。
- DM 秘密擲骰。
- 成功：解除。
- 失敗但結果「沒過20」：可重試。
- 「沒過25」：可能有不良後果；若是陷阱則觸發。

`[DM_DEFAULT]` 陷阱若已被觸發，可依陷阱條目使用攻擊 vs 閃避、抗噴吐、抗毒素等適合接口；不是所有陷阱都自動命中。

## 8. 文書解讀 `[D100_CANON]`

可解讀：

- 古代符文
- 失傳文字
- 不熟悉文字
- 不完整訊息

成功可理解約一頁內容的大意。

**文書解讀 ≠ 自動理解內容涉及的奧術理論。**

例如古魔法書可分：

```text
文書解讀 → 看懂文字
奧術知識 → 理解理論脈絡
辨識法術 → 辨識正在運作的魔法結構
魔法物品學 → 理解作為魔法物品的構造
```

## 10. 使用魔法裝置 `[D100_CANON]`

- 非施法者也可嘗試閱讀／使用魔法物品。
- 每次啟用裝置都可能需檢定。
- 使用者必須知道自己正在模仿什麼要素。
- 常用卷軸例：`須過 20 + 卷軸環數×5`。

## 11. 夢境潛入與神器級物品 `[D100_CANON]`

夢境潛入會在幻夢境擬似角色的素質、物品與技能，但來源表明文排除：

- 聖器
- 亞神器／來源其他表亦出現「次神神器」稱呼
- 神器

這些神器級物品**不會被一般擬似機制複製**。

幻夢境死亡不直接殺死主位面本體，但：

```text
每死亡一次 → SPI 永久 -1
```

技能等級可抵銷一定次數死亡懲罰；精神損益直接作用本體。

## 12. 搜集資訊 `[SRD_BRIDGE + GM_PROVISIONAL]`

目前 Google Sheet 的基本專長列中缺少獨立 `搜集資訊`，但 D100 自己有兩個明確引用：

```text
調查員 → 搜集資訊 / 搜索 +10/Lv
地方知識 Lv2+ → 搜集資訊 +10
```

GM 已明確同意：**以 D&D 3.5 `Gather Information` 補回這個缺失條目。**

### D100 重建

```text
搜集資訊（交涉，難度1）
判定 = 交涉 + 技能等級×10 + 其他修正
```

未購：依一般技能規則 `-20`；Lv0 移除未受訓減值。

### 常用難度

3.5 原始 DC 依 D100 既有技能的「須過 N」語法使用：

```text
一般城鎮／社群重大消息：須過10
特定傳聞、特定物件、地圖或較窄情報：通常須過15～25，必要時更高
```

### 時間與重試

```text
典型一次：1d4 + 1 小時
```

可以重試，但每次都重新花時間；若持續追問同一類敏感情報，可能引起注意。

### 既有 D100 加值

```text
調查員：+10 / Lv
地方知識 Lv2+：+10
```

這是**經 GM 允許的 3.5 reconstruction**，不是聲稱目前 Sheet 中仍存在那一列。

## 13. 戰鬥施法不是懸空的「專注技能」 `[GM_PROVISIONAL]`

`專注` 的實際 D100 接口已由 GM 第二輪補答確認：使用一般專長 `戰鬥施法`。

```text
未購戰鬥施法 → 戰鬥基礎值 -20
戰鬥施法 Lv0 → 戰鬥基礎值
戰鬥施法 LvN → 戰鬥基礎值 + N×10
```

哪些情境會觸發，參考 3.5 `Concentration` 的「施法受到干擾」邏輯；詳見 `00_core/magic.md`。

因此**不要再建立另一個獨立的「專注」技能**。

## 14. 一般專長中對 DM 很重要的已確認接口

- `閃避`：與近戰／遠程攻擊對抗。
- `盾牌使用`：閃避失敗後再判定，成功減傷。
- `格擋`：閃避失敗後、鎧甲前嘗試減傷。
- `快速反射`：提升抗噴吐。
- `鋼鐵意志`：提升抗毒素／抗控制／抗轉化。
- `不屈意志`：提升抗毒素／抗轉化／抗控制／強韌／靈魂／精神。
- `控制強迫解除`：控制失敗後可再檢定一次，並接受第二結果。
- `法術穿透`／`高等法術穿透`：與抗魔法互動。
- `魔法物品學`：魔法物品相關檢定每級 +10。
- `魔法陣基礎學`：解析大型魔法陣。
