# D100 語言索引

> 本檔整理上游基本技能「語言」與 2026-09-14 創角補答，供創角／驗卡快速查詢。完整 raw 來源仍在 `sources/sheet_mirror/`。

## 1. 語言技能本體 `[D100_CANON]`

`語言` 屬於交涉類技能。

來源表的核心語義：

```text
語言一般不需要技能檢定。
技能等級主要表示使用熟練度。
```

因此不要把語言當成每次說話都要擲骰的技能。

目前沒有完整、可追溯的「Lv0/Lv1/Lv2/Lv3 = 哪種 CEFR 式程度」對照表；不要自行補成正典。

## 2. 難度 `[D100_CANON]`

大多數一般語言：

```text
難度1
```

已確認的難度2語言：

```text
天界語
深淵語
龍語
德魯伊語
煉獄語
高等精靈語
古神語
```

若後續上游 Sheet 出現其他難度2語言，以 Sheet 為準更新本表。

---

## 3. 創角免費通用語 `[GM_PROVISIONAL]`

創角角色免費取得：

```text
通用語 Lv3
```

不消耗 CP。

這是創角模板贈與，不表示所有世界居民一律天然通用語 Lv3；NPC／特殊文化仍看其角色資料。

---

## 4. 施法者語言門檻 `[GM_PROVISIONAL]`

施法者創角至少需要：

```text
任一難度2語言 Lv1+
```

Lv1 已足以滿足「會一門高難度語言」的施法文化／教育門檻。

來源可以是：

- 種族贈送；
- 背景／模板贈送；
- 其他合法免費來源；
- 花 CP 購買。

若種族已送難度2語言，**不需要再買另一門**。

---

## 5. 基本職業模板推薦 `[GM_PROVISIONAL + SRD_BRIDGE]`

自動創角可以使用 3.5 class-related language 作基本模板：

```text
法師 → 龍語 Lv1
牧師 → 天界語／深淵語／煉獄語擇一 Lv1
德魯伊 → 德魯伊語 Lv1
```

這只是推薦，不是固定語言稅。

真正 hard gate 永遠是：

```text
至少一門難度2語言 Lv1+
```

例如：

```text
高等精靈種族若已免費取得高等精靈語 Lv1
→ 可以直接滿足施法者語言門檻
→ 不必為法師身分再額外買龍語
```

`../90_srd_bridge/CHARACTER_CREATION_CLASS_CULTURE.md`

## 6. Builder / validator 使用方式

### Hard check

```text
caster == true
→ 是否存在 difficulty >= 2 且 level >= 1 的 language？
```

若沒有，創角未完成。

### Recommendation

若需要自動補一門語言：

1. 先檢查種族／文化／背景是否自然提供難度2語言；
2. 再看職業基本模板；
3. 不要為了模板覆蓋更合理的文化語言。

### 不做的事

- 不要求所有法師都龍語；
- 不要求所有牧師都天界語；
- 不把通用語 Lv3 算成難度2施法門檻；
- 不自行發明語言熟練度精確對照表。
