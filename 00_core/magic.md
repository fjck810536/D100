# D100 施法核心

本檔整理來源 Sheet「施法者創角須知」「戰鬥流程」與一般專長中已確認的施法規則。

## 1. 施法職業前置 `[D100_CANON]`

### 法師

- 奧術知識（知識）難度2
- 黑魔導（感知）難度1
- 黑魔力（感知）難度1

### 吟遊詩人

- 吟遊知識（知識）難度2
- 表演（交涉）難度1
- 樂曲寫作（知識）難度1

### 德魯伊

- 自然知識（知識）難度2
- 自然神術（交涉）難度2

### 牧師

- 宗教知識（知識）難度2
- 神術（交涉）難度2

### 邪術師 / Warlock

- 魔能知識（知識）難度2
- 魔能施法（感知）難度2

### 術士

- 奧術知識（知識）難度2
- 血脈呼喚（交涉）難度2

## 2. 法術位 `[D100_CANON]`

來源表：

```text
法師法術位 = 自身環數×2 + INT調整值 + 魔法物品變動值 + 技能變動值
吟遊詩人法術位 = 自身環數×2 + CHA調整值 + 魔法物品變動值 + 技能變動值
德魯伊法術位 = 自身環數×2 + SPI調整值 + 魔法物品變動值 + 技能變動值
牧師法術位 = 自身環數×2 + SPI調整值 + 魔法物品變動值 + 技能變動值
邪術師法術位 = 自身環數×2 + CHA調整值 + 魔法物品變動值 + 技能變動值
術士法術位 = 自身環數×2 + CHA調整值 + 魔法物品變動值 + 技能變動值
```

注意：來源表明文強調 **法術位與記憶法術位是不同的東西**。

## 3. 總施法者等級 `[D100_CANON]`

```text
總施法者等級
= 本身環數×3
+ 其他技能／專長
+ 裝備變動值
```

供各法術效果使用。

## 4. 施法判定 `[D100_CANON]`

```text
施法判定
= 施法主屬性
+ 10 × (總施法者等級 / 3)
- 連續施法懲罰
- 此次法術環數 × 10
```

施法主屬性：

- 法師：感知
- 牧師：交涉
- 德魯伊：交涉
- 吟遊詩人：交涉
- 邪術師：感知
- 術士：交涉

`[OPEN_QUESTION]` 若總施法者等級 / 3 非整數時如何取整，來源片段尚未明示。

## 5. 連續施法懲罰 `[D100_CANON]`

若上個動作是**成功施法**，就觸發連續施法懲罰。

來源語意：

```text
連續施法懲罰 += 上一個成功法術環數 × 10
```

而且會連續累算。

DM 應追蹤施法鏈，不得每輪自動歸零，除非來源其他條文明確指定何時重置。

`[OPEN_QUESTION]` 連續施法懲罰何時正式清空／中斷，需要再由來源表完整整理。

## 6. 法術環數與法術位消耗 `[D100_CANON]`

來源表：

```text
法術位消耗
= 法術環數
+ 超魔專長數量
+ 特殊施法技能變動值
```

若自身法術位不足，不能施法。

## 7. SP 消耗 `[D100_CANON]`

```text
SP消耗
= 法術環數
+ 超魔專長數量
+ 特殊施法技能變動值
```

目前來源文字與法術位消耗公式相同；不要自行把兩者合併成同一資源。

## 8. 起始法術與記憶位 `[D100_CANON]`

來源表：

- 角色最高環數：取得該環 3 種法術 + 3 格記憶法術位。
- 每往下一環：再多 3 種法術 + 3 格記憶法術位。
- 長休後可以在已抄寫進法術書的法術中更換記憶法術。

德魯伊／牧師：

- 到達該環後自動習得該環所有基礎法術。
- 若是專長升階或萬法大全等額外來源法術，仍可能需要法術書輔佐。

## 9. 施法三要素 `[D100_CANON]`

一般施法不需要另外做命中，但必須確認法術的：

- 手勢
- 言語
- 材料

是否能被滿足。

個別法術若需要接觸攻擊、射線、投射等，依其法術／專長條文處理。

## 10. 戰鬥施法／專注 `[D100_CANON + GM_PROVISIONAL + SRD_BRIDGE]`

在敵方威脅範圍內一般施法屬於無防備動作，可引發藉機攻擊。

來源 Sheet 的 `戰鬥施法`（戰鬥，難度1）明文：

> 你可以在戰鬥中施展法術。在防禦、被擒或壓制狀態下施法或使用類法術能力，專注檢定可獲得每等級 +10 的加值。

GM 第二輪補答已確認：D100 **沒有另一個獨立的「專注」技能需要再找**；專注這條能力由 `戰鬥施法` 承載。

```text
未購「戰鬥施法」：
    戰鬥基礎值 -20

戰鬥施法 Lv0：
    戰鬥基礎值

戰鬥施法 LvN：
    戰鬥基礎值 + N×10 + 其他適用修正
```

### 何時要求專注／戰鬥施法

GM 明示可參考 D&D 3.5 `Concentration`：**凡是對角色執行施法行為造成實際干擾的情況，都可能要求戰鬥施法檢定。**

典型情境包括：

- 施法過程受到傷害；
- 持續傷害；
- 防禦施法；
- 被擒抱／壓制；
- 其他法術或環境干擾；
- 劇烈運動、顛簸、惡劣天候等妨礙施法動作；
- 移動中施法，而該移動未被 `移動施法` 的安全移動額度涵蓋。

3.5 在這裡提供的是**干擾情境與 Concentration 邏輯的參考**；實際骰法仍使用 D100 的 `戰鬥施法`，不得偷偷換回 d20。

若需要 3.5 的具體干擾門檻，應作 `[SRD_BRIDGE]` 使用；若 D100 能力有自己的明文門檻，D100 明文優先。

## 11. 法術傷害與豁免 `[D100_CANON]`

先讀法術條文，確認：

- 傷害類型
- 是否有抗噴吐等基礎豁免
- 是否半傷／減傷／完全無效
- 是否受法抗與元素抗性影響

來源戰鬥流程不支持「所有法術都先命中再豁免」這種統一模型。

## 12. 法術穿透 vs 抗魔法 `[D100_CANON]`

`法術穿透`：

- 每級提升判定成功率
- 可影響的法術環數與技能等級相關
- 與受術者的抗魔法作對抗
- 成功後，對方對此法術的抗性減免砍半

來源寫出的受術者抗魔法檢定修正：

```text
抗魔法檢定
= 抗魔法
- 法術穿透技能等級×10
- 施法主屬性調整值×5
```

`高等法術穿透`：

```text
抗魔法檢定
= 抗魔法
- 高等法術穿透技能等級×20
- 施法主屬性調整值×5
```

成功時可使對方無法對此法術進行抗性減免。

因此抗魔法在現行系統中主要具有**法抗／穿透層**功能，不應被 GPT 自動當成所有魔法的第一道 saving throw。

## 13. 法術瞬唱 `[D100_CANON]`

若角色有相關專長並於宣告階段宣告瞬唱：

- 可在瞬唱處理階段生效；或
- 扣住使用權，在之後適當時點做行動對應。

行動對應優先度：

```text
法術瞬唱 > 即時動作 > 自由動作 = 一般動作
```

## 14. 移動施法 `[D100_CANON + GM_PROVISIONAL]`

`移動施法`（戰鬥，難度1）明文：

```text
每技能等級可在施法時多移動 10 ft
```

且不能超過角色自身移動能力。

GM 第二輪補答釐清它的功能：

> `移動施法` 決定的是**施法時，在不影響施法的情況下可以移動的最大距離**。

因此它不是另一種專注技能，也不取代 `戰鬥施法`。

```text
移動距離在「移動施法」安全額度內
→ 移動本身不要求戰鬥施法／專注

移動方式或距離真的干擾施法
→ 依戰鬥施法／專注處理
```

其他傷害、擒抱、環境等干擾仍各自可能要求戰鬥施法。

## 15. 辨識法術 `[D100_CANON]`

`辨識法術`（知識，難度1）：

- 每級 +10 判定
- 可辨識施展中或作用中的法術
- 不同情況有不同難度
- 專精法師對專精學派 +10
- 禁制學派 -25
- `魔法天賦` 可提供加值

它不自動等於：

- 知道神器真名
- 知道全部神器權能
- 理解古代法術理論
- 解除法術

## 16. 使用魔法裝置 `[D100_CANON]`

`使用魔法裝置`（感知，難度2）：

- 每級 +10
- 可讓非施法者嘗試閱讀／啟動卷軸、法杖與其他魔法物品
- 每次啟動都可能需要檢定
- 使用者必須有意識地模仿需要的要素

來源常用卷軸例：

```text
須過 20 + 卷軸環數×5
```

## 17. 魔法調查的分層 `[DM_DEFAULT]`

面對魔法物品／古魔法書時，至少區分：

- 搜索：物理細節、機關、痕跡
- 估價：價值／古物性
- 魔法物品學：魔法物品結構理解
- 文書解讀：文字內容
- 辨識法術：正在作用的法術結構
- 奧術／宗教／位面等知識：理論與脈絡

不要一次成功就把所有層級資訊全送出。
