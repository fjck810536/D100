# D100 判定核心

## 1. 基本形式

`[D100_DERIVED]` 目前 D100 例子顯示，技能／攻擊等檢定採 **d100 roll-under + 成功餘裕**：

```text
判定值 T
擲 D100 得 R
成功餘裕 M = T - R
```

- `M >= 0`：視為通過該判定的基本成功線。
- `M < 0`：未通過。
- D100 內大量條文用「過 X」「沒過 X」描述結果，因此真正重要的不只是成功／失敗，還包含成功餘裕。

例：

```text
攻擊值 90，D100=30
90-30=60 → 過60
```

## 2. 固定門檻：「須過 X」

`[D100_CANON]` 多個技能直接使用「判定須過 X」。

例：騎術／騎乘條文可見：

- 以雙膝控制坐騎：須過5
- 避免摔落：須過5
- 緩和摔落：須過10
- 跳躍：須過20
- 戰鬥中控制坐騎：須過25

因此固定門檻的讀法是：

```text
M = 判定值 - d100
若 M >= 門檻 → 通過
```

## 3. 對抗檢定

`[D100_CANON]` 攻擊與閃避明文採對抗。

來源例：

```text
攻擊 90，D100=30 → 過60
閃避 80，D100=40 → 過40
攻擊結果高於閃避結果 → 命中
```

因此：

```text
M_A = A判定值 - A骰
M_B = B判定值 - B骰
較高成功餘裕者勝
```

此結構也存在於：

- 脫逃術 vs 繩技／擒抱
- 躲藏 vs 偵察
- 潛行 vs 聆聽
- 偽造文書 vs 偽造文書檢查
- 手上功夫 vs 偵察／搜索
- 唬騙 vs 察言觀色
- 交涉 vs 交涉
- 武器使用 vs 閃避
- 法術穿透 vs 抗魔法

## 4. 雙方都失敗 `[OPEN_QUESTION]`

正典例子沒有明確回答：

```text
A：60，骰90 → -30
B：50，骰95 → -45
```

是否因 `-30 > -45` 而由 A 勝出，目前不能當作正典。

`[DM_DEFAULT]` 在取得更明確原規則前：

- 若行動本身要求主動方成功（攻擊、解除、說服），**主動方基本檢定失敗則行動失敗**；不因防禦方失敗得更慘而反轉。
- 若雙方都成功，再比較成功餘裕。
- 某技能條文若明文寫不同，依技能條文。

## 5. 平手 `[OPEN_QUESTION]`

對抗成功餘裕完全相同時，現資料未找到統一規則。

`[DM_DEFAULT]`：

- 維持現狀／防守方優先。
- 若無明確防守方且結果必須分勝負，擲 D100 高低決勝。

此裁定必須視為暫定。

## 6. 01 / 100、爆擊與大成功 `[OPEN_QUESTION]`

D100 有武器爆擊、大成功相關條文，但目前沒有一條已確認的全域規則能支持：

- 01 一定自動成功
- 100 一定自動失敗
- 01 = 大成功
- 100 = 大失敗

因此 DM **不得套用 CoC 習慣**。

武器爆擊應依角色／武器／專長的爆擊規則處理。來源表亦有「偵察大成功」語句，但全域大成功公式仍待整理。

## 7. 判定值超過 100

`[D100_DERIVED]` D100 的加值系統可讓判定值超過100。此時不要把它硬截成「100%」。

因為成功餘裕仍有差異：

```text
T=130，骰80 → 過50
T=180，骰80 → 過100
```

在對抗與「須過 X」中，超過100的判定值仍有機械意義。

因此本系統應理解為：

> **d100 作為 1–100 的隨機擾動，判定值與成功餘裕可超過百分率語義。**

## 8. 未受訓與技能 Lv0

`[D100_CANON]`

- 沒有該技能時，若需要使用該技能判定，通常有 **-20% / -20 判定減值**。
- 可以購買技能 **Lv0** 來避免這個未受訓 -20。
- 技能 Lv0 的成本仍依技能 CP 公式處理。

## 9. 加值語法

大量 D100 技能採：

```text
技能判定 = 所屬基礎值 + 技能等級×10 + 其他加減值
```

但不是所有技能都完全同型；應以該技能條文為準。

常見加減值：

- 技能等級：+10 / level
- 專長支援：+5、+10 等
- 環境工具：+10 / -10 等
- 速度、裝甲、姿勢、距離：依條文

## 10. 秘密檢定

`[D100_CANON]` 已明文存在：

- 偽造文書：DM 秘密擲
- 解除裝置：DM 秘密擲
- 聆聽：DM 可秘密擲

`[DM_DEFAULT]`：搜索陷阱、伏兵察覺、未知超自然侵蝕等若公開骰會直接洩漏隱藏資訊，也可採秘密擲骰。

## 11. 重試

部分技能明文有自己的重試規則。

例如解除裝置：

- 成功：解除
- 失敗但「沒過20」：可重試
- 「沒過25」：可能觸發不良後果；陷阱會觸發

因此不要建立「所有技能都能一直重骰」的通則。

`[DM_DEFAULT]` 若技能未明文，只有在方法、資訊或環境改變時才給新的有意義檢定；否則以時間換結果或沿用第一次檢定所決定的資訊上限。

## 12. CP 重骰

`[D100_CANON]`：跑團中 **1 CP 可換一次重骰**，但劇情骰、寶藏骰除外。

`[OPEN_QUESTION]`：

- 同一判定能否連續花多個 CP 重骰？
- 重骰是否強制接受新結果？
- 神器／靈魂等特殊判定是否另有限制？

在沒有 house rule 前，DM 不得偷偷增加額外限制。
