# D100 戰鬥流程

本檔以來源 Sheet「戰鬥流程」為核心。

## 1. 一輪只有 1 秒 `[D100_CANON]`

D100 戰鬥中的每輪實際行動時間：

```text
1 round = 1 second
```

這是與 D&D 3.5 最大的結構差異之一。所有從 3.5 移植的輪數、DOT、再生、持續時間、每輪觸發都必須重新換算。

## 2. 每輪流程 `[D100_CANON]`

### A. 偷襲輪

有偷襲輪的角色可先與團隊商談順序後依序偷襲。

### B. 確認行動順序

```text
行動順序 = DEX + DEX調整值
```

值越高越早行動。

若同值：

1. 有「精通先攻」者優先。
2. 否則擲 D100 決定。
3. 平手狀況每輪重新確認。

角色可於每輪開始前先告知 DM，主動降速來延後行動順位。

### C. 確認宣告順序

```text
宣告順序 = INT + INT調整值
```

**INT 越高，宣告越晚。**

這代表高 INT 角色有更多資訊後才做宣告。

若同值：擲 D100 決定誰較晚宣告；每輪重新確認。

角色也可放棄此輪行動，宣告下一輪要最快行動；多人同時如此時以 DEX、精通先攻、D100 決定優先。

### D. 全員依序宣告

熟練玩家建議每次宣告時間 1 分鐘；逾時來源規則可視為放棄該輪宣告。

DM 要確認宣告是否合理；完全違背常理時可：

- 勸阻
- 視為無效
- 增加判定難度

施法者此時要確認：

- 法術
- 導入的超魔專長
- 法術位是否足夠

### E. 處理法術瞬唱

多名瞬唱角色同時使用時：

- 依施法主屬性／來源規則的 INT 相關順位處理
- 同值擲 D100

### F. 依行動順序行動

逐一執行已宣告內容。

### G. 想改變原宣告

角色可做**運動判定**：

- 成功：可改成新宣告
- 失敗：本輪失去原先宣告內容

### H. 回合末

處理：

- DOT
- 增益效果是否結束
- 負面效果是否結束

## 3. 三種動作 `[D100_CANON]`

### 一般動作

通常消耗整輪。

例：

- 一般施法
- 全回合移動
- 一般遠程攻擊
- 觀察法術
- 解析法術
- 急救
- 從背包找特定物品
- 潛行
- 謹慎移動
- 一般近戰攻擊（需半速）

全回合移動可以輔助跳躍、攀爬、特技或一般近戰攻擊作助跑。

### 自由動作

通常每輪可做 **2 次**，但兩者不得互相矛盾。

例：

- 警戒半速移動
- 從霍法便利袋取物
- 喝藥水
- 啟動魔法物品
- 抽武器
- 使用卷軸
- 翻滾
- 跳躍
- 攀爬
- 特技

DM 要確認角色當前雙手、姿勢與狀態允許動作。

### 即時動作

可在自身回合、移動順序行動階段之後的任意時點啟動。

- 不得與當前姿勢／狀態矛盾。
- 每一種即時動作正常每輪只能用一次。

例如：

- 及時備戰
- 瞬步

## 4. 行動對應優先度 `[D100_CANON]`

```text
法術瞬唱 > 即時動作 > 自由動作 = 一般動作
```

### 即時動作對應

可在他人行動的適當時點啟動尚未使用的即時動作。

### 法術瞬唱對應

若宣告時扣住瞬唱使用權，可在自己或他人行動後的適當時點使用。

正常每輪一個法術瞬唱權；除非能力另有規定。

## 5. 移動 `[D100_CANON]`

來源公式：

```text
正常移動上限 = (DEX調整值 + 技能／專長 + 魔法物品變動值) × 5 ft
```

若公式結果與角色／種族／特殊能力條文衝突，以更具體條文為準。

## 6. 藉機攻擊 `[D100_CANON]`

在敵方威脅範圍內做無防備動作會吃一次藉機攻擊。

來源例：

- 施法
- 全回合移動
- 一般遠程攻擊
- 觀察法術
- 解析法術
- 急救
- 從背包找物
- 喝藥水
- 使用卷軸

DM 可依同類型無防備行為裁定。

## 7. 一般攻擊 `[D100_CANON]`

```text
攻擊判定
= 戰鬥
+ 武器使用技能等級×10
+ 專長／技能輔助
+ 魔法物品變動值
```

通常與敵方「閃避」對抗。

來源例：

```text
攻擊90，d100=30 → 過60
閃避80，d100=40 → 過40
60 > 40 → 命中
```

## 8. 防禦層 `[D100_CANON]`

### 閃避

`閃避` 與近戰／遠程攻擊對抗；成功則避開該次攻擊。

### 格擋

閃避失敗後可嘗試格擋，且必須在鎧甲使用前。

```text
格擋減傷
= 格擋等級×2
+ 武器使用等級×1.5
+ 魔法武器變動值
```

最多不超過該次近戰傷害。

### 盾牌使用

閃避失敗後可進行盾牌使用檢定，成功減少傷害。

```text
盾牌減傷
= 盾牌種類
+ 技能等級×2
+ 魔法物品變動值
```

### 擅長鎧甲

```text
鎧甲減傷
= 技能等級×2
+ 鎧甲傷害減免
+ 魔法裝備等效變動值
```

## 9. 武器傷害 `[D100_CANON]`

來源一般武器使用：

```text
武器傷害
= STR調整值
+ 武器本身傷害
+ 武器使用技能等級×1.5
+ 魔法武器變動值
```

戰鬥流程較完整的最終物理傷害：

```text
力量調整值
+ 武器本身傷害
+ 武器使用技能等級×1.5
+ 使用魔法武器加值/2
- 格擋減傷
- 擅長鎧甲減傷
- 專長物抗
- 魔法物品物抗
+ 被穿透的總物抗
```

若個別武器／技能明文有不同公式，採個別條文。

## 10. 元素附傷與抗性 `[D100_CANON]`

武器附加元素傷害獨立處理：

```text
元素傷害
- 專長元素抗性
- 魔法物品元素抗性
- 專長法抗
- 魔法物品法抗
+ 被穿透元素抗性
```

同一抗性穿透來源只作用一次。

## 11. 爆擊與自然大成功 `[D100_CANON + GM_PROVISIONAL]`

戰鬥流程明文：若攻擊骰出武器爆擊：

- 該下武器傷害取滿
- 不同武器可有不同爆擊效果
- 該次物理與魔法物品元素傷害可使魔法物品提供的元素抗性、法抗、物抗無效
- 其他專長／魔法物品來源的抗性穿透仍計算

2026-09-24 GM 補答進一步確認：

- **自然 01 的攻擊／傷害大成功進入高於一般成功的 exceptional outcome 層，並包含該武器既有爆擊品質。**
- AO 以角色已形成的傷害意圖、瞄準／手段、物件狀態、時空條件與 committed 世界因果裁定最終傷勢。
- 「使對方失去行動能力並保住生命」可在自然大成功時表現為精準部位重創與失能；「殺死目標」可在物理條件支持時表現為致命 exceptional outcome。
- 自然 100 的攻擊／傷害大失敗走「事與願違／墨菲定律」方向，AO 可由世界因果裁定機械事故、時機錯位、意外擊中、傷勢尺度偏離、位置逆轉、連帶損失或其他重大橫禍。
- AO 是自然極值的 final adjudicator，並記錄世界 basis 與角色 intent。

全域武器爆擊範圍仍依武器／專長條文整理；個別條文提供更具體效果時，作為 exceptional outcome 的機械材料。

詳細原則見 `00_core/checks.md` 與 `sources/GM_CLARIFICATIONS_2026-09-24_CRITICAL_RESULTS.md`。

## 12. DOT 與增減益 `[D100_CANON]`

### DOT 物理

```text
DOT總傷害
- 專長物抗
- 魔法物品物抗
+ 被穿透總物抗
```

### DOT 元素

```text
DOT總傷害
- 專長元素抗性
- 魔法物品元素抗性
- 專長法抗
- 魔法物品法抗
+ 被穿透元素抗性
+ 被穿透法抗
```

### 疊加

- 同一 DOT 來源可以疊算。
- 同一負面效益只作用一次。
- 同一法術／類法術正面效益：同一施法體系只作用一次，高等蓋低等。
- 不同施法體系來源可疊加。
- 牧師神術：不同信仰神祇來源可以疊加。

## 13. 藥水負荷 `[D100_CANON]`

5 輪內角色能承受的藥水總量與 CON 調整值相關。

超量時：

```text
抗毒檢定
= 抗毒素
- (飲用／吞服總數 - 承受上限) × 10
```

失敗：CON 獲得 1 點負向減值。

持續型藥水在效果結束前持續計入承受量。
