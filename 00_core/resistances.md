# 五大抗性與三種特殊判定

本檔把現行 D100 的公式與目前可由技能／效果推得的語義分開記錄。

## 1. 五大抗性公式 `[D100_CANON]`

```text
抗毒素 = RES + CON
抗控制 = RES + WIS
抗轉化 = RES + RES
抗噴吐 = RES + DEX
抗魔法 = RES + INT
```

共同都有 `RES`，可視為角色面對外來作用時的基本抵抗底盤；第二屬性描述抵抗方式。這一語義是 `[D100_DERIVED]`。

## 2. 抗毒素

### 明確用途 `[D100_CANON]`

戰鬥流程中，角色在 5 輪內飲用／吞服超過自身藥水承受量時，需要抗毒素檢定；失敗會造成 CON 負向減值。

### DM 使用語義 `[D100_DERIVED]`

優先處理：

- 毒液、毒藥
- 有毒氣體
- 藥物過量
- 毒素型生理傷害
- 以生理感染／侵蝕為核心的效果

如果「血液」只是轉化的媒介，而真正效果是改寫形態，應優先使用抗轉化，不要因媒介是血就必定用抗毒素。

## 3. 抗控制

來源表存在：

- `鋼鐵意志`：提升抗毒素／抗控制／抗轉化
- `控制強迫解除`：控制檢定失敗後可再次檢定
- `察言觀色`：可發現某人受魔法控制

因此 `[D100_DERIVED]` 抗控制主要面向：

- 強制命令
- 行為支配
- 魅惑／精神支配
- 強迫逃跑、跪下、攻擊同伴等外部意志介入

核心問題：

> **外力能否替角色決定原本不願意做的行動／意志方向？**

不是所有精神傷害都叫抗控制。

## 4. 抗轉化

公式為 `RES + RES` `[D100_CANON]`。

`[D100_DERIVED]` 主要處理：

- 石化
- 變形
- 強制異變
- 肉體改造
- 種族／生物型態改寫
- 眷屬化
- 某些同化、寄生後的形態改寫

核心問題：

> **外力能否把角色目前的形態／存在狀態改寫成另一種狀態？**

若效果真正抽取、吞噬或摧毀靈魂，優先改用「靈魂」。

## 5. 抗噴吐

來源名稱是「抗噴吐」 `[D100_CANON]`，但現行表已顯示其用途大於字面：

- 跳遠失敗時可用抗噴吐攀住邊緣
- 魔導砲範圍攻擊要求範圍內角色進行抗噴吐；成功半傷
- 法術傷害公式明文提到「抗噴吐等基礎豁免判定」
- `快速反射` 直接提升抗噴吐

因此 `[D100_DERIVED]` 它可視為 D100 的**反射／範圍型豁免接口**，包括：

- 龍息
- 爆炸
- 範圍火焰／閃電／酸液
- 崩塌、墜落邊緣等反應事件
- 法術條文明寫可由抗噴吐豁免的效果

它不等於一般「閃避」：

- 閃避常用於和一個攻擊者的命中做對抗。
- 抗噴吐常用於已覆蓋區域的效果，決定是否避開／減輕傷害。

## 6. 抗魔法

公式 `RES + INT` `[D100_CANON]`。

現行表最明確的機械互動來自 `法術穿透` 與 `高等法術穿透`：

- 法術穿透要與受術者的抗魔法做對抗。
- 成功可使對方法術／抗性減免砍半。
- 高等法術穿透成功可使對方無法對該法術進行抗性減免。
- 相關檢定公式會以技能等級與施法主屬性調整值降低受術者抗魔法。

因此 `[D100_DERIVED]`：

> 抗魔法主要是**法抗／魔法減免與法術穿透接口**，而不是所有魔法效果都額外附送的一次萬用豁免。

DM 不得把：

```text
魔法來源 → 先抗魔法 → 再抗控制／轉化／精神
```

當作無條件通則。

若某個魔法物品／詞綴明文要求「敵方進行抗魔法檢定」，則依該條文執行。

## 7. 三種特殊判定 `[D100_CANON]`

```text
強韌 = CON × 5
精神 = RES × 5
靈魂 = SPI × 5
```

### 強韌 `[D100_DERIVED]`

處理肉體承受極限：

- 惡劣環境
- 憋氣／窒息
- 力竭、耐久
- 某些即死或生命承受檢定

現行聖器級詞綴「奪命」會要求強韌檢定；失敗可立即死亡。

### 精神 `[D100_DERIVED]`

處理：

- 強烈心智負荷
- 恐怖／認知崩解
- 外來精神資訊灌入
- 心智承載，而非直接奪取行動控制

### 靈魂 `[D100_DERIVED]`

處理：

- 抽魂
- 靈魂損傷
- 靈魂被奪取／吞噬
- 角色存在核心受到直接作用

## 8. 精神、抗控制、靈魂的切線

```text
精神：我能不能承受這個經驗／資訊？
抗控制：別人能不能決定我的行為／意志？
靈魂：我的存在核心能不能被傷害／奪取？
```

同一能力可以有不同階段，但只有階段真的不同才分開判定。

例：

```text
直視神祇化身 → 精神
神祇隨後下達具強制力的命令 → 抗控制
神祇直接抽取靈魂 → 靈魂
```

## 9. 自願接受效果 `[OPEN_QUESTION]`

目前尚需確認：

- PC 能否主動放棄抗轉化接受友方變形？
- 能否關閉／放棄抗魔法接受友方法術？
- 抗控制是否影響自願心靈連結？

`[DM_DEFAULT]`：除非效果條文明文「不可自願」，角色可以選擇不抵抗一個自己已知且願意接受的效果；但神器、詛咒、未知效果不因此自動變成可安全接受。
