# characters/

每名 PC／重要 NPC 建議使用獨立 Markdown 檔。

建立 PC 時複製：

`templates/PC_TEMPLATE.md`

命名例：

```text
characters/alice.md
characters/bob.md
```

## DM 規則

- 角色檔內的實際數值優先於 DM 記憶。
- HP、SP、持續效果等即時變化可先記在 session state，session 結束再回寫角色永久狀態。
- 不要替玩家補未選專長、未學技能、未持有裝備。
- 若角色檔缺少 P0 數值（例如目前未決的基礎移動），不要默認套 D&D 數值；先依該團 house rule 或已知角色表處理。
