# campaign/

這個目錄放**該團的正典狀態**，優先級高於一般 DM default 與 SRD bridge。

建議檔案：

- `house_rules.md` — 本團採用的明示 house rules
- `setting.md` — 世界設定與不可變事實
- `current_state.md` — 當前世界／任務／NPC 狀態
- `secrets.md` — DM 秘密，只供 DM／Agent 使用

## GPT 使用規則

開團時先讀：

1. `house_rules.md`
2. `setting.md`（若存在）
3. `current_state.md`（若存在）
4. 最新 session 檔
5. 相關角色檔

如果 campaign 檔案與通用 D100 core 衝突，以 campaign 明示 house rule 為準。

## 不要做

- 不要把玩家猜測寫成 setting fact。
- 不要把 DM 秘密提前移到玩家可見狀態。
- 不要因為聊天裡曾經提過某個可能性，就直接固化成正典。
- 新增世界事實時，要能指出它是玩家行動造成、DM 設定、或既有 campaign 資料。
