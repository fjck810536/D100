# D100 裁定 Regression Cases

這些不是固定劇本，而是拿來測 GPT 是否真的在使用 D100，而不是偷套其他系統。

每次更換模型、改 DM 指令或大改 core rules 後，可以拿這些案例做 smoke test。

---

## Test 1 — 寶箱飛箭機關

### 情境

A 寶箱內有飛箭機關。PC 搜索失敗，沒有發現機關，直接開箱。

### DM 應做

1. 不因搜索失敗就宣布箭矢自動命中。
2. 開箱後觸發機關。
3. 依陷阱設計選擇合理接口：
   - 單一飛箭：陷阱攻擊 vs 閃避 `[DM_DEFAULT]`
   - 面狀箭雨／爆發：可改用抗噴吐
4. 若箭頭帶毒，命中後再進抗毒素。
5. 若公開說「抗毒素」會提前洩漏箭有毒，可等接觸／症狀揭露後處理或暗擲。

### 不應做

- 自動命中，理由只是「你沒找到陷阱」。
- 直接使用 D&D Reflex save 數值。
- 把抗噴吐與閃避無差別混用。

## Test 2 — 舊日支配者之血眷屬化

### 情境

具有眷屬化權能的古神血液碰到 PC。

### DM 應先問效果機制

若真正作用是：

```text
血液作為媒介 → 改寫角色形態／物種／存在狀態
```

主要防禦：

```text
抗轉化
```

若另有真正獨立的生理毒害：

```text
毒害階段 → 抗毒素
轉化階段 → 抗轉化
```

若轉化完成後又有強制服從：

```text
控制階段 → 抗控制
```

### 不應做

只因為「血」就一律用抗毒素；也不應一次叫玩家連骰抗毒、抗轉、抗控、精神、靈魂，除非能力真的有五個不同因果階段。

## Test 3 — 奪心魔抽魂

### 情境

某奪心魔能力不是單純腦控，而是把 PC 的靈魂拉離身體。

### 主要接口

```text
靈魂 = SPI×5
```

若能力是一股主動力量，可設：

```text
奪魂值 vs PC 靈魂
```

做對抗。

### 後果

來源 core 尚沒有「靈魂判定失敗統一狀態」。因此能力條目應自己寫：

- 失敗一次的效果
- 多次失敗是否累積
- 抽離完成條件
- 是否可被中斷／救回

這些不能由 GPT 假裝已有正典。

### 不應做

把所有心靈相關效果都丟給抗控制。若效果真的抽魂，優先是靈魂。

## Test 4 — 奈瑟瑞爾古魔法書

### 情境

PC 閱讀非常古老的魔法書。

### 正確分層

如果只想看懂文字：

```text
文書解讀
```

如果要理解其中奧術歷史／理論：

```text
奧術知識
```

如果文字／書頁本身正在運行法術結構：

```text
辨識法術
```

如果它作為特殊魔法物品具有異常結構：

```text
魔法物品學
```

### 若書有精神灌注 + 轉化

合理多階段：

```text
閱讀／理解
→ 精神灌注：精神
→ 只有灌注真正建立模板後
→ 轉化：抗轉化
```

### 不應做

- 看見「古魔法書」就自動叫 SAN check。
- 一次奧術知識成功就揭露全部神器權能。
- 因為來源是魔法就無條件額外加一道抗魔法。

## Test 5 — 直視希瑞克化身

### 情境

PC 主動直視希瑞克化身。

### 若效果是神性／認知衝擊

```text
精神
```

因為問題是：

> 心智能否承受所見／所理解的存在？

### 若化身接著下達超自然命令

```text
抗控制
```

### 若直接觸碰／奪取靈魂

```text
靈魂
```

### 不應做

把「看見神祇」與「被神祇控制」當成同一件事。

## Test 6 — 樸素神器書與位面級魔法背景

### 情境

一本外觀極樸素的神器古書，其魔法效應不是局部放射，而是與整個物質位面共延展。

若該團採用 3.5 artifact aura bridge，artifact 可具有 Overwhelming aura；但：

```text
Overwhelming = 強度
```

不自動等於：

```text
位面級範圍
```

位面級範圍必須是神器自身條目。

### 探測結果 `[DM_DEFAULT]`

如果整個位面都處於相同背景：

```text
偵測存在：成功
定位書本：未必成功
分類背景：可能成功
從局部差分找源頭：可能做不到
```

DM 不應說「神器因為太強所以 detect magic 看不到」；也不應說「偵測到 Overwhelming，所以立刻知道這本書就是源頭」。

# Regression 判準

一個合格的 D100 DM 模型應該穩定做到：

- 五抗與三特殊判定不混成一池。
- 判定看效果性質，不只看來源標籤。
- 不濫加多重 saving throws。
- 知道搜索、偵察、文書解讀、辨識法術、魔法物品學是不同資訊層。
- 知道 D100 一輪 = 1 秒。
- 不自動使用 CoC SAN。
- 不自動使用 3.5 Fort/Ref/Will。
- 不把高技能當成能創造不存在的感官資訊。
- 規則缺漏時標記 open/default，而不是編造原文。
